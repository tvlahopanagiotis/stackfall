# Stackfall

A falling-block puzzle game with a roguelite Run mode. Installable, works offline.

- **Android (Chrome):** open the site, menu ⋮ → *Add to home screen* → *Install*.
- **Mac (Chrome):** click the install icon at the right of the address bar.
- **Mac (Safari 17+):** File → *Add to Dock*.

Rebuild after changing the game: `python3 build.py path/to/stackfall.html`, then commit `index.html` and `sw.js`.
